# FT9201 `2808:9338` di Linux — Investigasi sampai Solusi

Dokumen ini merangkum bring-up fingerprint reader berikut:

```text
USB ID     : 2808:9338
USB name   : Focal-systems.Corp FT9201Fingerprint
Chip sensor: 0x6893
Resolusi   : 64x80, 500 DPI
Endpoint   : bulk OUT 0x02, bulk IN 0x83
```

Status akhir: **berfungsi end-to-end melalui libfprint dan fprintd**. Enrollment
tersimpan untuk user Linux dan `fprintd-verify` menghasilkan
`verify-match`.

## Ringkasan solusi

Masalah awal bukan sekadar USB ID yang belum dimasukkan ke driver. Device ini
tidak menggunakan protokol `focaltech_moc` upstream. Solusi akhirnya terdiri
dari tiga bagian:

1. Driver libfprint khusus melakukan handshake dan capture dengan protokol USB
   `2808:9338` yang diperoleh dari trace driver vendor.
2. Frame mentah `64x80` diproses oleh matching engine resmi Windows,
   `ftWbioEngineAdapter.dll`, melalui PE loader lokal tanpa Wine.
3. Driver dipasang berdampingan dengan libfprint distro dan diarahkan hanya ke
   service `fprintd` melalui systemd drop-in.

Library libfprint distro **tidak ditimpa**.

## Temuan penting selama investigasi

### 1. Menambahkan PID ke `focaltech_moc` tidak cukup

Menambahkan `2808:9338` ke tabel USB membuat libfprint mengklaim device, tetapi
driver berhenti pada command pertama. Ini membuktikan bahwa kesamaan vendor
tidak berarti kesamaan protokol.

### 2. Asumsi upload firmware ternyata salah

Percobaan awal memakai firmware FT9338W menghasilkan:

```text
firmware readback mismatch
got=0e 0e 0e 0e expected=02 32 ab 02
```

Trace library vendor memperlihatkan bahwa device ini sudah memiliki firmware
operasional dan tidak perlu di-upload saat open. Memaksa download firmware
justru membawa driver ke jalur yang salah.

### 3. Identitas sensor berasal dari reply 32 byte

Handshake open vendor:

```text
control OUT request=0x34 value=0x0003 index=0x0000
control OUT request=0x6f value=0x0000 index=0xff00
control OUT request=0x34 value=0x0003 index=0x0000
control OUT request=0x6f value=0x0020 index=0x9180
bulk IN 32 bytes
```

Reply mengandung chip `0x6893`, manufacturer `0xaa`, width `64`, dan height
`80`.

### 4. Protokol deteksi jari dan capture

Deteksi jari memakai vendor control-IN:

```text
request=0x43, length=1
00 = jari lepas
01 = jari menempel
```

Urutan capture utamanya:

```text
control OUT 0x34 value=0x0003 index=0x0000
control OUT 0x6f value=0x1400 index=0x9080
bulk IN 5120 bytes
```

`5120 = 64 * 80`; frame tidak memiliki header tambahan.

### 5. Matching engine Windows dapat digunakan tanpa Wine

Frame berhasil diterima oleh engine resmi:

```text
VerticalLineLength 80
HorizontalLineLength 64
VerticalImageResolution 500
HorizontalImageResolution 500
```

Engine menetapkan maksimal 18 sampel enrollment dan dapat menolak sampel yang
terlalu mirip dengan `enroll-remove-and-retry`.

### 6. SELinux dan `MemoryDenyWriteExecute`

Loader awal menata PE ke executable memfd. Di dalam service `fprintd`, SELinux
menolak write ke:

```text
/memfd:ftengine (deleted)
```

Selain itu, unit `fprintd` memakai:

```ini
MemoryDenyWriteExecute=true
```

Solusinya bukan mematikan SELinux atau hardening. Saat instalasi, DLL ditata
menjadi sidecar `.image` berdasarkan RVA. Saat runtime:

- code dipetakan read/execute;
- data dan IAT dipetakan read/write-private;
- tidak ada halaman write+execute;
- tidak ada executable memfd yang ditulis oleh `fprintd`.

## Instalasi langkah demi langkah

Semua perintah berikut dijalankan dari root checkout repository:

```bash
cd advan-workplus-ft9338-linux
```

### 1. Pasang dependensi build

Contoh Fedora:

```bash
sudo dnf install git meson ninja-build gcc cabextract python3 \
  glib2-devel gusb-devel pixman-devel nss-devel \
  libgudev-devel systemd-devel
```

Nama paket pada Debian/Ubuntu berbeda; lihat `README.md` di repo.

### 2. Siapkan blob vendor

Driver membutuhkan matching engine dari driver Windows resmi. Script repo
mengambil CAB dari Microsoft Update Catalog:

```bash
./scripts/fetch-blobs.sh
```

File yang dibutuhkan:

```text
blobs/ftWbioEngineAdapter.dll
```

Hash DLL yang berhasil diuji:

```text
SHA-256 ca34ba1e8494fc84a9ac31dd5c003e825d847484e5e3509f099de123d7953c6a
```

DLL bersifat proprietary dan tidak semestinya dimasukkan langsung ke commit
source code.

### 3. Build

```bash
./scripts/build.sh
```

Artefak utama:

```text
libfprint/build/libfprint/libfprint-2.so.2.0.0
```

### 4. Tes langsung sebelum instalasi

```bash
sudo env \
  FT9201_ENGINE_DLL="$PWD/blobs/ftWbioEngineAdapter.dll" \
  LD_LIBRARY_PATH="$PWD/libfprint/build/libfprint" \
  timeout 180 \
  "$PWD/libfprint/build/examples/enroll"
```

Enrollment berhasil bila berakhir dengan pesan seperti:

```text
ft9201: enrollment committed, template 251254 bytes
```

Program contoh menyimpan template relatif terhadap current working directory
dalam `test-storage.variant`. Ini hanya untuk tes, bukan storage `fprintd`.

### 5. Instal side-by-side untuk fprintd

```bash
sudo ./scripts/install.sh
```

Installer melakukan hal berikut:

- memasang libfprint custom ke `/usr/local/lib/ft9201`;
- memasang DLL dan sidecar image ke `/usr/lib/libfprint-2/`;
- memasang udev rule `2808:9338`;
- membuat systemd drop-in untuk `fprintd`;
- mempertahankan libfprint distro dan hardening service.

### 6. Enrollment user

Jalankan tanpa `sudo` agar template dimiliki user yang benar:

```bash
fprintd-enroll
```

Tempel dan angkat jari setiap sampel. Ubah area yang menyentuh sensor: tengah,
ujung, bawah, kiri, kanan, sudut, dan sedikit rotasi. Enrollment belum tersimpan
sampai muncul:

```text
Enroll result: enroll-completed
```

### 7. Verifikasi

```bash
fprintd-list "$USER"
fprintd-verify
```

Hasil sukses:

```text
Listing enrolled fingers:
 - #0: right-index-finger
Verify result: verify-match (done)
```

## Troubleshooting

### `enroll-remove-and-retry`

Engine menolak sampel karena terlalu mirip, kualitas rendah, atau jari/sensor
berminyak. Angkat jari sepenuhnya, bersihkan sensor, keringkan jari, lalu pakai
area jari yang berbeda.

### `NoEnrolledPrints`

Enrollment belum mencapai `enroll-completed`, atau enrollment dilakukan sebagai
user lain/root. Ulangi `fprintd-enroll` tanpa `sudo`.

### `Remote peer disconnected` atau `enroll-unknown-error`

Periksa service:

```bash
sudo journalctl -u fprintd -n 100 --no-pager
```

Jika log menyebut `/memfd:ftengine`, pastikan source terbaru sudah dibuild dan
installer dijalankan ulang sehingga file berikut ada:

```text
/usr/lib/libfprint-2/ftWbioEngineAdapter.dll.image
```

Jangan menonaktifkan SELinux dan jangan mengubah
`MemoryDenyWriteExecute=true` menjadi false.

### Melihat progress engine

```bash
sudo journalctl -u fprintd --since "5 minutes ago" --no-pager | \
  grep -E 'coverage|sample count|quality|enroll'
```

### Device terkunci setelah proses dihentikan

Tunggu beberapa detik agar `fprintd` melepas claim. Jika perlu:

```bash
sudo systemctl restart fprintd
```

## Rollback

Semua integrasi sistem dapat dibatalkan:

```bash
cd advan-workplus-ft9338-linux
sudo ./scripts/install.sh --uninstall
```

Rollback menghapus library side-by-side, DLL/sidecar, udev rule, dan systemd
drop-in. Libfprint bawaan distro tetap utuh.
